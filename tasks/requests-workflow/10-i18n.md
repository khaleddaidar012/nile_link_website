## Objective
Translate all new workflow statuses, buttons, alerts, and notification strings into human-readable English and Arabic using `next-intl`.

## Current Implementation
Raw keys like `portal.requests.status_quote_provided` are exposed if translations are missing.

## Problem
Missing translations break the illusion of a polished, professional platform.

## Proposed Solution
Map all defined states from `02-request-state-machine` to their corresponding UI strings.
Example:
- `en.json`: `"status_quote_provided": "Quotation Ready"`
- `ar.json`: `"status_quote_provided": "عرض السعر جاهز"`

## Files To Modify
- `messages/en.json`
- `messages/ar.json`

## Acceptance Criteria
- [ ] No raw translation keys are visible in the UI.
- [ ] Arabic translations are professional and context-accurate.

## Dependencies
- `02-request-state-machine`
- `05-customer-portal`
